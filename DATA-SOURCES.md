# Data sources and third-party terms

This page lists every third-party input Overhear for Alexa+ uses at build time or at
runtime, what each one is used for and the clause or terms that permit it. The project
ships publicly, so the record here is complete and each entry is checked against the repo
rather than assumed.

Status is `OK` when the governing clause is known and quotable. Status is `PENDING` when
something must still be read before a live run against the real service.

## Notes on the AWS services

Amazon Bedrock, Amazon Nova, Amazon Polly, Amazon S3 and Amazon DynamoDB are all called at
runtime under the AWS Service Terms. Their outputs are used inside the product the operator
runs. None of them are redistributed as standalone artifacts by this repo.

The one open item is the model-level terms. The service terms are known and quotable now.
The usage terms for the exact foundation model are read and accepted when a live AWS run is
set up, which is why that row is marked `PENDING` rather than `OK`.

dependencies) is not shipped in any published artifact and so adds no runtime or
